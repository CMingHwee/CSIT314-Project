# CSIT314 Project User Stories

1. As a User Admin, I want to create user accounts (User Admin, Interior Designer, Customer or Platform Management), so that users can access the system with the appropriate permissions.
2. As a User Admin, I want to view a list of all user accounts and their status, so that I can monitor who has access to the platform.
3. As a User Admin, I want to update user account information (e.g. reset password, change role), so that I can correct errors or adjust user permissions.
4. As a User Admin, I want to suspend a user account, so that I can revoke access for users who violate terms or are inactive.
5. As a User Admin, I want to search user profiles by name, email, or role, so that I can quickly find specific users in a large database.
6. As a User Admin, I want to create a user profile containing personal/professional details for a user, so that the platform has complete records for all actors.
7. As a User Admin, I want to view the detailed user profile of any user, so that I can verify their identity and confirm their details before granting them access to the platform.
8. As a User Admin, I want to edit user profile information (e.g. address, company registration), so that I can correct outdated info or assist users who cannot self-update.
9. As a User Admin, I want to suspend a user profile, so that inactive profiles do not clutter the public search results.
10. As a User Admin, I want to search user profiles by Company Name or Location, so that I can generate lists of IDs for specific regions.
11. As a User Admin, I want to log into the system securely, so that I can access the administrative dashboard.
12. As a User Admin, I want to log out of the system, so that I can secure the administrative tools when leaving my workstation.
13. As an Interior Designer, I want to create my company information, so that customers can learn about my business and verify my legitimacy.
14. As an Interior Designer, I want to view my company information, so that I can verify all details are correct and up-to-date before customers see them.
15. As an Interior Designer, I want to update my company information, so that my profile remains accurate and reflects any changes in my business.
16. As an Interior Designer, I want to delete my company information, so that my business is no longer visible on the platform if I choose to leave.
17. As an Interior Designer, I want to search my company information, so that I can quickly locate specific details within my profile.
18. As an Interior Designer, I want to log into the system securely, so that I can access my dashboard and manage my company information.
19. As an Interior Designer, I want to log out of the system, so that I can secure my company information when leaving my workstation.
20. As an Interior Designer, I want to create current Interior Design Project (IDP), so that I can allow myself and others to monitor the progress of the IDP.
21. As an Interior Designer, I want to view  current Interior Design Project (IDP), so that I can check the progress of the IDP.
22. As an Interior Designer, I want to update  current Interior Design Project (IDP), so that I can modify the IDP to the customer’s specifications.
23. As an Interior Designer, I want to delete  current Interior Design Project (IDP), so that I could cancel a project if the contract surrounding the IDP lapses.
24. As an Interior Designer, I want to search for  current Interior Design Project (IDP), so that I could accurately find the specific IDP to match with any ongoing projects.
25. As an Interior Designer, I want to create  past Interior Design Project (IDP), so that I can save a successful work done in interior design by adding it to my portfolio.
26. As an Interior Designer, I want to view  past Interior Design Project (IDP), so that I can reference from a past IDP to consider modification of a current IDP for improvements.
27. As an Interior Designer, I want to update  past Interior Design Project (IDP), so that I can modify the IDP to fix any inaccuracies that are found post IDP.
28. As an Interior Designer, I want to delete  current Interior Design Project (IDP), so that I could remove a project that suffered a catastrophe that is not caused by myself, and thus remove the stain to my reputation by association.
29. As an Interior Designer, I want to search for  past Interior Design Project (IDP), so that I could either find a past IDP for referencing, or to showcase my work.
30.As a customer, I want to log in to the web site or application so that I could access Interior Design Projects made by the company and save the necessary information in case I am a repeat customer.
31. As a customer, I want to log out of my account, so that I could remove access from others in seeing my account details freely.
32. As a customer, I want to search for an Interior Design Project (IDP), so that I could find any similar IDPs that this company has done that are similar to my queries.
33. As a customer, I want to view an Interior Design Project (IDP), so that I could check for suggestions in case I am not too particular about what I want for an IDP that suits my queries.
34. As a customer, I want to save an Interior Design Project (IDP) into a shortlist or favourite list, so that I could have an easier time finding for IDPs that I would like to reference without searching through the wider list for anything similar to my queries and show interest in that specific IDP.
35. As a customer, I want to search within a shortlist for an Interior Design Project (IDP), so that I could find a saved IDP to help in my decision making to decide whether to engage the services of this company.
36. As a customer, I want to view within a shortlist for an Interior Design Project, so that I could more easily use the references found inside to check if the company could do the same for my queries.
37. As an Interior Designer, I want to view the number of views to the Interior Design Projects (IDP) within my portfolio, so that I could check and estimate the traffic flow to various projects and allow me to work future projects in such a direction.
38. As an Interior Designer, I want to view the number of times any of my Interior Design Projects (IDP) within my portfolio being shortlisted or favourited, so that I can measure the quality of my various IDPs compared to the current market standards.
39. As a Platform Management Staff, I want to log in, so that I could have the requisite access level to allow me to do my job.
40. As a platform management staff member, I want to log out of the platform, so that no one else can access my account or the company’s data on a shared or unattended device.
41. As a Platform Management Staff, I want to create a new Interior Design Project (IDP) category, so that there is an easier way for both the Interior Designer, and the Customer, to search for IDPs based on the most relevant categories.
42. As a Platform Management Staff, I want to view an existing Interior Design Project (IDP) category, so that I could ensure that the correct categories for IDP are present for correct management of IDP listings.
43. As a Platform Management Staff, I want to update an existing Interior Design Project (IDP) category, so that I could ensure that the category for IDPs remain relevant and current to the present market.
44. As a Platform Management Staff, I want to delete an existing Interior Design Project (IDP) category, so that I could remove obsolete or redundant categories that are no longer needed for whatever reason.
45. As a Platform Management Staff, I want to search for an existing Interior Design Project  (IDP) category, so that I could ensure that new entries of categories for IDP are not duplicates of existing IDPs as well as checking if a category exists that needs further action to be taken upon.
46. As a Platform Management Staff, I want to generate daily reports of the daily views and patterns, so that the company could judge the traffic flows to the company online platform and adjust anything accordingly.
47. As a Platform Management Staff, I want to generate weekly reports of the view trend as well as all the specific modifications done by the Interior Designers and User Admins, so that the company can ensure that everything is accounted for.
48. As a Platform Management Staff, I want to generate monthly reports of the company online platform monthly performance back to the company, so that the company can tally up its records and use the gathered data and trends to adjust to the market, to the performance of its employees, and to the traffic flow to the online platform.
